# g2-navi

A personal walking and transit navigation app for Even Realities G2 smart glasses (work in progress).

- Transit routing: [Transitous](https://transitous.org/) ([data sources](https://transitous.org/sources/))
- Map data: © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors

The source code will be published here under an open-source license once the prototype is ready.

## Contact

Please open an [issue](https://github.com/famio-eng/g2-navi/issues) for any questions or concerns, including from data and API providers.
